# Support

This repository is maintained as a historical research archive.

- Use [GitHub Discussions](https://github.com/X-Sub/Telemetry-System/discussions)
  for interpretation, archival context, and general questions.
- Use [GitHub Issues](https://github.com/X-Sub/Telemetry-System/issues) for
  reproducible defects in maintained tools or documentation.
- Use private vulnerability reporting for security or safety-sensitive reports.

Commercial support, hardware certification, replacement parts, and guaranteed
compatibility with current CodeWarrior, Altium, LabVIEW, or Simulink releases
are not provided.

When asking for help, include the relevant path, commit, host operating system,
tool version, and exact error. Remove credentials, personal data, and real
mission telemetry first.
